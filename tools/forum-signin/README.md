# 论坛签到回归与维护说明

对象：`scripts/自用论坛辅助签到自写.js`。使用Node内置assert/VM与仓库已有Playwright，不向真实论坛发送请求，不读取用户浏览器账号或Cookie。样例是按适配逻辑构造的最小DOM/响应，不是当前网站页面快照。

## 运行

在仓库根目录执行：

```powershell
node --check 'scripts/自用论坛辅助签到自写.js'
node tools/forum-signin/run.mjs
openspec validate improve-forum-signin-reliability-and-experience --strict
git diff --check
```

## 超时、分类与任务恢复

- GM请求默认20秒，传给管理器并设置本地期限；页面fetch期限覆盖响应体。完成/异常清除计时器，迟到回包不能改变已结束等待。
- 未提交的临时网络/服务错误最多尝试三次，等待3秒、6秒；Retry-After上限60秒。401/登录跳转需登录，明确验证页需人工验证，403权限及结构失效停止自动重试。
- 已提交后回包丢失的自动复查只检查，不重复点击、提交、发帖或领取。网络复查有次数上限；仍无证据保留结果未知。失败原因与可恢复状态分别记录。
- 直签各站立即并行，不设置执行名额或等待队列；执行及重试等待独立续约。直签租约30秒、每10秒续约；页面任务10分钟。普通页面刷新继续站点自身的检查及后续流程，不因旧的结果未知或入口点击而永久只读；跨日旧操作不得写成今日成功。
- 显式“重新检查”和人工失败/跳过检查通过任务来源保持只读，旧版无来源的隐式只读标记自动解除。ZodGame已提交的表单继续只查结果。SS同盟使用独立新版流程，不信任旧成功缓存或泛用动作记录；本标签新提交记录只在点击可用回复按钮时写入，按日期、帖子及账号关联，确认后删除。每次本人检查最多一次过滤请求，不遍历其他人的分页；不叠加主引擎90秒轮询。验证码入口跳转继续安装验证通过后的提交监听。
- GM没有通用原子比较交换；共享租约发现已有任务并启动复读，**不保证极端同时写入时的绝对跨实例互斥**。同实例Map确定防重，实际提交结果未知时避免自动重复提交。
- 页面使用非敏感参数`__bbs_task`；核对共享任务后仅移除该参数，关联留在当前标签sessionStorage。其他标签、人工成功及丢失关联不能授权关闭。管理器没有句柄或跨域登录丢失关联时提示手动检查。
- 前台各站立即独立打开标签，用户轮流激活即可继续原有签到流程；没有“继续下一项”或“暂缓”队列操作。旧版本未执行的排队记录解除后可直接执行。
- 缺少GM值监听时使用单一5秒可见期/任务期检查，隐藏且无任务时停止；可见、focus、展开及本地午夜补读。面板关闭及配置草稿不受异步完成影响。

## 备份、恢复与清理

配置页“备份、恢复与历史”提供入口。备份为UTF-8 JSON：

```json
{
  "type": "BBSSignHelperBackup",
  "schemaVersion": 1,
  "exportedAt": "2026-10-09T12:00:00+08:00",
  "config": {
    "targetSettings": {},
    "customTargets": [],
    "preferences": {
      "autoOpenDashboardOnAttention": false,
      "autoClosePageAfterSign": false,
      "historyRetentionDays": 0
    }
  }
}
```

默认仅导出配置。勾选状态后增加`states.successDates`（目标到日期）及`states.dailyStatus`（日期到目标状态）；保留来源，运行中/排队/已打开归一为待检查。凭据、日志、租约、页面句柄、待关闭与短时撤销不导出，URL凭据及敏感参数剔除。

导入限制5MiB、200个自定义目标、1000个历史日期、20000条每日记录，检查类型/版本、HTTP(S)网址、唯一ID、枚举及有效日期。先预览，再按选中的配置/状态分区替换，未选分区保留。替换状态使旧任务代次失效；昨日仍为昨日，不恢复执行权或自动签到。

应用前保存最近一份本地恢复快照（同样限制5MiB）与事务标记；写入失败尝试恢复，启动发现未完成导入先恢复。GM多key写入不是原子事务。恢复失败保留快照/标记并停止站点自动执行，可在控制台重试恢复或下载可导入的恢复备份；未恢复前不能以新导入覆盖快照。

历史默认保留全部。7/30/90天包含今日，按本地日历日计算；手动清理先显示日期范围与记录数，自动每天最多处理20个过期日期。只清理本脚本每日详细状态的汇总和拆分key，不删配置、今日、最近成功日期或任务。缩短保留期前可先导出含状态备份。

## 诊断维护

目标行“更多 → 查看诊断”只读取本站近期失败记录，可导出/清空本站。无请求时显示状态与阶段，不发新请求。原有全量下载和清空油猴菜单保留。

日志按任务/尝试归属，保留3天、80会话、每会话50条、文本6000字符级截断。统一脱敏URL、头、JSON、表单、可识别HTML字段、错误及证据摘要，包含nonce/_nonce、Token、Cookie、Authorization、formhash、safeid等。旧日志读取、展示及导出再次脱敏。只记录脚本自身请求，没有网页全量拦截或API候选探测。

维护站点时优先更新最小DOM/响应样例，同时补正反例和提交计数断言。不能用普通全文成功、其他用户排行或编辑器草稿放宽完成条件。在线验证需逐站核对登录、当日完成/未完成、人工验证与提交后刷新，并记录实际页面日期；勿将构造样例称为真实签到成功。
