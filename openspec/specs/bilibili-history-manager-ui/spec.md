# bilibili-history-manager-ui Specification

## Purpose

为设置、历史管理、统计三个页签及公共弹窗提供完整统一的视觉与交互体验，使日常配置、记录检索和数据操作具有清晰层级、即时反馈及键盘和窄屏可用性，并保留现有用户功能。

## Requirements

### Requirement: 管理面板采用完整统一的视觉体系
管理面板 MUST 统一布局、导航、排版、间距、表单、按钮和状态反馈，使用深石墨导航、暖白内容背景与蓝色主操作；偏好设置、历史管理、数据统计及新增云同步四个并列模块与公共弹窗 MUST 使用一致的视觉规则。

#### Scenario: 桌面打开管理面板
- **WHEN** 用户在桌面视口通过现有入口打开管理面板
- **THEN** 系统 MUST 默认显示设置页，提供清晰的侧栏导航、页标题、内容区和关闭入口
- **AND** 四个模块 MUST 具有可识别的当前选中状态和一致的控件样式，云同步 MUST 有独立导航入口，不藏在维护分类

#### Scenario: 空数据与有数据均可展示
- **WHEN** 用户分别查看空历史、少量记录和大量记录
- **THEN** 各模块 MUST 提供适合当前状态的布局，不得依赖虚构统计数字或真实视频封面才能成立
- **AND** 云同步未配置、同步中、无备份、失败及待选择状态 MUST 均有完整布局和明确操作，不能只显示一排无说明按钮

### Requirement: 设置页具备明确分组与样式预览
设置页 SHALL 将现有配置组织为播放与提示、页面标记、标签样式和诊断维护等清晰分组，并提供仅作用于预览区的实时标签预览。

#### Scenario: 修改标签样式草稿
- **WHEN** 用户调整位置、透明度、进度条或阈值
- **THEN** 预览区 MUST 即时展示对应效果，覆盖已访问、不同观看进度及多 P 状态
- **AND** 保存前 MUST 不写入正式设置，也不得改变页面上真实视频的标记

#### Scenario: 所有既有设置与维护操作可访问
- **WHEN** 用户使用新设置页
- **THEN** 原有显示开关、续播提示、悬浮按钮隐藏规则、透明度、位置、低高阈值、调试日志、下载及清空日志、恢复面板位置和适用时的当前视频跳转 MUST 继续可用

### Requirement: 设置草稿与保存状态可见
系统 MUST 在面板会话内保留设置草稿，明确展示未保存、保存中、已保存和保存失败状态，并让保存与恢复默认入口始终易于找到。

#### Scenario: 编辑设置后切换页签
- **WHEN** 用户编辑设置但未保存，切换到历史管理再返回
- **THEN** 草稿 MUST 保留，且未保存状态 MUST 仍然可见

#### Scenario: 输入非法阈值
- **WHEN** 低高阈值为空、不是有限整数、超出 1 至 99 或低阈值不小于高阈值
- **THEN** 系统 MUST 显示字段旁错误并阻止保存，正式设置 MUST 保持原值

#### Scenario: 恢复默认设置
- **WHEN** 用户选择恢复默认设置
- **THEN** 默认值 MUST 进入当前草稿并更新预览，用户保存后才应用到正式设置

#### Scenario: 带未保存修改关闭面板
- **WHEN** 用户存在设置草稿修改并尝试关闭面板
- **THEN** 系统 MUST 提供保存后关闭、放弃修改和继续编辑的清晰选择
- **AND** 保存失败时 MUST 保留面板和草稿

### Requirement: 历史管理呈现清晰的查询与批量操作层级
历史页 MUST 清晰区分搜索筛选、数据列表、批量操作、分页和数据维护，保留现有搜索、排序、分页、多选、删除撤销、导入导出及保留周期清理能力。

#### Scenario: 选择多条历史
- **WHEN** 用户选中一条或多条记录
- **THEN** 系统 MUST 显示选中数量和相关批量操作
- **AND** 当前页全选框 MUST 正确反映全选或部分选中状态，零选中时删除选中 MUST 不可执行

#### Scenario: 查询无结果
- **WHEN** 用户的搜索或筛选条件没有匹配记录
- **THEN** 系统 MUST 展示无匹配结果反馈并提供清除条件入口，且不得与尚无任何历史的空状态混淆

### Requirement: 统计页具备一致且准确的展示层级
统计页 MUST 保留已有统计卡片、状态及进度分布、近期趋势和范围切换能力，并以统一的数字、标签、坐标及状态色展示。

#### Scenario: 切换统计时间范围
- **WHEN** 用户在 7、30、90 天之间切换
- **THEN** 图表标题、范围状态、数值和空状态 MUST 同步更新
- **AND** 图表 MUST 提供可读说明，不能仅依赖颜色表达状态

### Requirement: 公共弹窗与操作反馈一致
系统 SHALL 为确认、加载、成功、失败及撤销提供统一的可交互反馈，并确保确认和进度信息在管理面板上方可见。

#### Scenario: 确认保留周期清理
- **WHEN** 用户请求清理且存在候选记录
- **THEN** 二次确认 MUST 明确显示保留周期、截止时间和预计删除数量
- **AND** 取消 MUST 不删除数据；该流程 MUST 保留现有保留周期清理规范的全部约束

#### Scenario: 操作失败
- **WHEN** 保存、导入、同步或删除失败
- **THEN** 界面 MUST 展示失败状态与可用的重试或关闭操作，解除进行中状态，并保留仍可恢复的输入或备份

#### Scenario: 删除完成后撤销
- **WHEN** 删除成功且处于现有撤销期限内
- **THEN** 系统 MUST 提供文字明确、可用键盘触发的撤销按钮，不能仅让整块提示消息承担隐式点击操作

#### Scenario: 撤销需要等待存储
- **WHEN** 用户点击撤销而恢复操作尚未完成
- **THEN** 系统 MUST 立即展示进行中反馈并阻止重复提交，持续到真实完成或失败
- **AND** 失败 MUST 提供重试反馈，成功 MUST 按实际恢复和跳过数量报告

### Requirement: 键盘与窄屏可用
面板 MUST 具备可访问名称、正确的焦点管理、键盘导航及可见焦点样式，并在桌面和 390 像素宽视口中保持完整可用。

#### Scenario: 使用键盘打开与关闭
- **WHEN** 用户打开面板并用 Tab、Shift+Tab 和 Escape 操作
- **THEN** 焦点 MUST 进入面板并限制在当前顶层弹窗中，Escape MUST 只处理最上层弹窗
- **AND** 关闭后焦点 MUST 回到仍存在的触发入口

#### Scenario: 窄屏查看历史和设置
- **WHEN** 视口宽度为 390 像素或用户放大页面
- **THEN** 导航 MUST 调整为顶部布局，设置控件与关闭保存入口 MUST 可见且可操作
- **AND** 面板 MUST 无整体横向溢出，历史和统计的必要横向滚动 MUST 限制在各自内容区域

#### Scenario: 用户要求减少动态效果
- **WHEN** 系统启用减少动态效果偏好
- **THEN** 面板 MUST 关闭非必要位移和入场动画，操作状态仍须清晰

### Requirement: 页面隔离与现有入口兼容
新界面 MUST 仅作用于脚本自己的界面区域，保留现有入口与悬浮按钮隐藏规则，不依赖外部视觉资源；除用户配置后主动执行或启用定时任务所需的 WebDAV 请求外，面板 MUST 不增加页面请求。

#### Scenario: 管理面板与 Bilibili 原页面共存
- **WHEN** 用户在现有匹配页面打开、操作并关闭管理面板
- **THEN** 原页面导航、播放器、按钮和布局 MUST 不被脚本的面板样式污染
- **AND** 关闭后原页面滚动状态 MUST 恢复，观看记录功能 MUST 继续运行

#### Scenario: 云同步入口按需联网
- **WHEN** 用户仅打开面板但未请求 WebDAV 操作，且自动同步未启用
- **THEN** 面板 MUST 不因渲染其他模块而发起 WebDAV 请求；备份列表 MUST 在用户打开云同步模块或刷新时按需加载

### Requirement: 设置分类与预览按当前任务展示
设置页 MUST 提供常用设置、悬浮入口、观看标记、维护四个可用键盘操作的分类入口，每次只展示一个分类，分类栏及全局保存入口 MUST 保持易于访问。

#### Scenario: 分类切换保留草稿
- **WHEN** 用户修改设置并切换分类，或切换到历史页后返回设置
- **THEN** 所有未保存修改 MUST 保留，设置页 MUST 返回会话内选择的分类；分类切换不得写入正式设置

#### Scenario: 预览随分类切换
- **WHEN** 用户选择悬浮入口或观看标记分类
- **THEN** 系统 MUST 仅展示该分类对应的预览；常用设置和维护不显示无关预览
- **AND** 桌面预览与表单并排，窄屏按顺序排列且无整体横向溢出

#### Scenario: 保存时定位其他分类中的错误
- **WHEN** 用户在当前分类保存，而其他分类存在非法字段
- **THEN** 系统 MUST 阻止保存、自动切换到错误所属分类、展开必要折叠项并聚焦可编辑输入；同时保留所有草稿

### Requirement: 左下角入口具有统一视觉与信息层级
系统 MUST 为视频页进度入口与非视频页设置入口提供统一的圆角、图标、细边框和轻阴影。视频页 MUST 支持简洁与详细模式，信息更新不得改变用户选择的外观或拖拽位置。

#### Scenario: 默认详细模式展示记录
- **WHEN** 用户打开有观看记录的视频页，且尚未自定义外观
- **THEN** 入口 MUST 使用浅色、蓝色强调、100% 大小、不透明背景的小卡片，展示状态、可用的观看时间和百分比、保存时间以及适用时的分 P 信息
- **AND** 已访问、读取中或缺失时间的记录 MUST 显示真实状态，不得显示虚构进度、无效日期或 undefined

#### Scenario: 简洁模式和非视频页
- **WHEN** 用户选择简洁模式或访问非视频页
- **THEN** 视频入口 MUST 以胶囊展示图标、状态与可用百分比，并在悬停说明及可访问名称中保留完整可用记录信息；非视频入口 MUST 显示图标与“观看记录”文案
- **AND** 非视频入口在两种模式下 MUST 仅显示图标与“观看记录”，宽度随内容自适应，不显示重复辅助文案或虚构视频进度

#### Scenario: 默认入口减少页面遮挡
- **WHEN** 用户使用100% 大小、详细模式查看两类入口
- **THEN** 视频入口 MUST 在保留完整观看信息的同时将宽度控制在 170 CSS 像素内、常规记录高度控制在 105 CSS 像素内
- **AND** 非视频入口 MUST 为单行，宽度不超过 115 CSS 像素、高度不超过 40 CSS 像素

#### Scenario: 显示范围与页面切换
- **WHEN** 用户使用任一既有显示范围，或视频页尚未取得记录，或通过 SPA 在不同页面切换
- **THEN** 当前路由对应的显示规则 MUST 生效，左下角至多存在一个真实入口，视频无记录时使用设置入口作为回退
- **AND** 右下角历史同步按钮与页面观看标记 MUST 保持原有行为

### Requirement: 悬浮外观支持适度自定义与兼容读取
系统 MUST 提供浅色／深色主题、六位十六进制强调色、80%–160% 的整数自定义大小比例、60–100 的整数背景不透明度百分比以及简洁／详细模式。默认值 MUST 为浅色、#00aeec、100%、100、详细；背景透明度不得降低文字与图标的不透明度。

#### Scenario: 保存并重新加载
- **WHEN** 用户保存合法外观设置并重新加载页面
- **THEN** 两种入口 MUST 使用已保存的外观，现有显示范围、位置与其他设置 MUST 保留

#### Scenario: 旧设置或损坏字段
- **WHEN** 已存设置缺少新字段，或新字段包含未知枚举、非法颜色、空值或越界数值
- **THEN** 系统 MUST 对每个无效字段独立使用默认值，同时保留其他有效配置、旧位置和观看记录

#### Scenario: 兼容原有三档大小
- **WHEN** 旧设置使用 small、medium 或 large 大小
- **THEN** 系统 MUST 分别将其转换为 92%、100% 或 108%，并允许用户继续输入 80%–160% 范围内的任意整数比例

#### Scenario: 视频信息具有明确视觉重点
- **WHEN** 视频入口使用详细模式并具有观看时间
- **THEN** 观看时间字号 MUST 至少为状态文字的两倍，百分比紧随时间，保存时间使用较小字号
- **AND** 宽度 MUST 随内容收紧，保存时间不带重复前缀，各信息区块保留适当垂直间距

#### Scenario: 设置界面输入无效值
- **WHEN** 用户提交空值、非法颜色、无效枚举或非整数及越界透明度
- **THEN** 系统 MUST 阻止保存、显示相关字段错误并保留草稿，正式设置不得变化

### Requirement: 悬浮外观预览遵循设置草稿语义
设置页 MUST 提供明确的悬浮入口外观区及独立预览，预览覆盖视频和非视频入口；即使真实入口被全部隐藏，用户仍能预览外观。

#### Scenario: 修改草稿与恢复默认
- **WHEN** 用户修改外观或恢复悬浮外观默认值
- **THEN** 预览 MUST 即时更新，页面真实入口、正式设置与位置 MUST 保持不变，切换管理页签后草稿 MUST 保留
- **AND** 局部恢复外观默认值 MUST 不改变显示范围、位置或其他设置；全局恢复默认仍遵循既有草稿流程

#### Scenario: 保存成功或失败及放弃
- **WHEN** 用户保存、放弃或带草稿关闭面板
- **THEN** 系统 MUST 沿用保存后关闭、放弃和继续编辑流程；仅持久化成功后刷新真实入口
- **AND** 失败时 MUST 保留草稿与错误反馈，真实入口保持原外观；预览不得绑定拖拽或打开管理面板的行为

### Requirement: 悬浮入口可移动且支持键盘操作
两种入口 MUST 共享已保存位置，保留默认距左、下边缘各 15 像素的位置，兼容旧位置格式。入口 MUST 支持指针拖拽、键盘聚焦及 Enter／Space 打开设置，具备可见焦点；减少动态效果偏好 MUST 关闭非必要位移动画。

#### Scenario: 点击与拖拽分离
- **WHEN** 用户点击入口或执行超过 5 像素移动阈值的拖拽
- **THEN** 单击 MUST 打开设置与历史管理，视频页保留当前视频上下文；拖拽结束 MUST 只保存位置且不得误打开面板
- **AND** 指针取消、入口销毁与重复刷新 MUST 不留下拖拽监听器或重复触发行为

#### Scenario: 旧位置与视口变化
- **WHEN** 用户加载旧位置、缩小视口至 390 像素宽、改变大小或切换信息模式
- **THEN** 入口 MUST 在保持原位置意图的前提下约束于视口内，不产生横向溢出；无效位置 MUST 回到默认位置
- **AND** 合法且可见的旧位置 MUST 得到保留

#### Scenario: 恢复位置与隐藏后的可达性
- **WHEN** 用户从设置页或脚本菜单恢复位置，或隐藏全部悬浮入口
- **THEN** 两个恢复位置操作 MUST 清除同一份位置数据并将当前入口恢复左下角默认位置，不改变外观设置
- **AND** 隐藏全部入口后 MUST 仍可从脚本菜单打开设置

### Requirement: 云同步工作台具有清晰信息层级
云同步模块 SHALL 分别呈现同步状态与主操作、连接配置、同步与保留策略、备份列表及恢复入口；控件、标题、间距、边框、图标和状态色 MUST 与既有管理面板一致，错误与危险操作不得只靠颜色区分。

#### Scenario: 查看与配置云同步
- **WHEN** 用户打开云同步模块
- **THEN** 顶部 MUST 能直接查看当前状态、最近成功同步时间及立即同步入口，连接配置、策略和备份区 MUST 有明确分组与主次操作
- **AND** 配置未保存时 MUST 显示草稿状态，切换到其他模块再返回不丢草稿；关闭管理面板沿用保存、放弃、继续编辑流程

#### Scenario: 窄屏浏览独立模块
- **WHEN** 用户在 390 像素宽视口打开云同步模块并切换四个导航入口
- **THEN** 导航、连接表单、备份列表与操作区 MUST 可读可用且无整体横向溢出，必要内容可以纵向滚动
- **AND** 操作状态刷新 MUST 不重置输入、焦点或滚动位置

### Requirement: 云同步控件使用一致的定制外观
系统 SHALL 为云同步的输入、按钮、同步频率选项、保留天数、备份选择及恢复确认提供统一设计的外观和 hover、focus、selected、disabled、loading、error 状态；MUST 不使用浏览器默认 alert／confirm／prompt 完成用户流程，也不得依赖未定制原生 select、数字微调器或日期选择器呈现主要交互。

#### Scenario: 修改同步频率和备份设置
- **WHEN** 用户操作关闭／每小时／每天选项、保留天数或备份列表
- **THEN** 频率 MUST 使用同风格分段选项，保留天数 MUST 使用带单位及字段错误的定制输入，已有备份 MUST 通过设计过的列表选择而非原生日期弹框
- **AND** 文本与密码输入 MUST 支持正常输入、复制粘贴、密码管理器及标签关联，不为外观丢弃基础语义

#### Scenario: 键盘操作与恢复确认
- **WHEN** 用户使用 Tab、方向键、Enter、Space 或 Escape 操作相应控件与恢复弹窗
- **THEN** 控件 MUST 按其语义响应，具有可见焦点及可访问名称；恢复和本地／云端选择 MUST 使用脚本自有统一弹窗，保留焦点管理与取消路径
- **AND** 自定义外观 MUST 不引入外部组件库、远程字体或持续装饰动画，自动同步仍遵循静默规则
