# Design

## Context

动机见 [proposal.md](./proposal.md)。现有 `UIComponent.showViewPanel` 每次创建 div，使用两段 p 显示记录，并绑定 mousedown 与文档 mousemove/up；`updateViewPanelProgress` 依赖 p 的顺序。`showQuickEntry` 创建固定位置 button，没有拖拽。二者分别使用 `.bvh-view-panel` 和 `.bvh-quick-entry`，位置仅视频面板读取 `bvh_panel_position`。

`HistoryManagerPanel` 已有草稿、异步保存、标签预览和全局恢复默认。`SettingsManager.save` 成功写入后才更新 CONFIG，适合直接复用。设置页和菜单各有一段恢复位置逻辑，当前只处理视频面板。视频页无记录回退到快捷入口时，还会经过非视频显示条件，需要在统一入口中明确按当前路由判断。

本设计用于提前确定视觉、配置和指针生命周期，保留现有 `bilibili-history-manager-ui` 规范，以新增要求扩展，不替换既有设置与键盘约束。

## Goals / Non-Goals

**Goals:**
- 将内容、外观与位置处理分离，让进度刷新无需重建入口，让实际入口和预览共享视觉规则。
- 在原脚本内部实现，保持历史数据协议、GM key 和脚本权限兼容。

**Non-Goals:**
- 不提供自定义 CSS、任意字体、任意圆角、逐项信息开关、自动吸边、收起动画或自动主题探测。
- 不改版右下角同步按钮、播放器、观看标记或整个管理面板；不增加跨标签页外观实时广播承诺。

## Decisions

### 1. 克制的小卡片与胶囊

采用与现有管理面板协调的暖白／深石墨背景，蓝色强调，细边框和柔和投影。详细视频入口为按内容自适应宽度的小卡片：顶部图标、状态及分 P；中部以约为状态字号两倍的观看时间作为重点，百分比紧随其后；下部为细进度轨道与弱化的保存时间。无进度时隐藏轨道，读取中仅展示真实状态。简洁模式为单行胶囊，显示图标、状态和可用百分比，完整记录通过 title 与可访问名称补足。非视频入口使用相同图标和材质，显示“观看记录”，两种信息模式均只保留图标与“观看记录”，宽度随内容自适应。

卡片圆角为基础字号的 0.9 倍，胶囊圆角为高度的一半；基础字号 13 像素，按用户输入的 80%–160% 比例调整，入口最小高度为 36 像素。尺寸通过字号、间距与图标尺寸调整，不使用整体 transform 缩放，避免命中区域与位置计算不一致。数字使用等宽数字特性，沿用本地中文字体，不请求字体资源。

强调色用于图标和轨道，正文使用主题固定的高对比文字色；任意强调色不承担唯一状态表达。浅／深背景建议 #fffdf9／#202631，文字建议 #243040／#f3f6fa。背景透明度用背景色 alpha，边框、文字与图标保持清楚。不依赖磨砂模糊，减少页面兼容与性能成本。hover 仅轻微强化阴影，focus-visible 使用清楚轮廓。

备选的纯图标按钮虽然更小，但会隐藏现有观看信息；大面积玻璃或渐变会增加背景干扰，因此不采用。

### 2. 五个独立外观字段

在 `bvh_settings` 中加入平铺字段，与现有标签样式配置保持一致：

| 字段 | 取值 | 默认 |
| --- | --- | --- |
| floatingTheme | light / dark | light |
| floatingAccentColor | #RRGGBB | #00aeec |
| floatingSize | 80–160 整数百分比 | 100 |
| floatingOpacity | 60–100 整数 | 100 |
| floatingMode | compact / detailed | detailed |

原有 `floatingButtonVisibility` 继续独立决定显示范围。新增集中默认值和归一化方法，加载和保存边界均使用。旧设置缺失字段与损坏字段按字段回退；设置表单保存前严格校验、标记错误并定位控件，避免将无效输入悄悄保存为默认值。设置写入仍合并旧字段，不覆盖无关设置。

不使用嵌套对象，避免现有浅合并、草稿复制和 dirty 判断引入额外迁移；不把外观写入记录导出文件。

### 3. 共享外观渲染与独立预览

在脚本内增加小型悬浮入口辅助模块，集中处理归一化、CSS 变量和内容槽位。保留已有 DOM id 作为定位契约，新增脚本前缀类和 data 属性表示图标、状态、进度和保存时间，不再依赖 `p:first-child`。使用原生 button 或等效完整键盘语义，复用内联 SVG 图标，更新文本使用 textContent。

`showViewPanel` 在相同入口可复用时仅更新内容；`updateViewPanelProgress` 只更新相关槽位与可访问名称。切换视频和非视频入口前释放旧实例。当前路由先决定 visibility，再决定显示记录或无记录回退入口，避免无记录视频误用非视频隐藏规则。

设置页按用户后续反馈改为常用设置、悬浮入口、观看标记、维护四个分类。分类导航位于滚动内容区之外，分类选择保存在面板会话内，不写入 GM 设置。悬浮分类将显示范围、五个外观控件和局部恢复默认集中展示，对应视频／非视频预览在桌面右侧、窄屏下方显示；观看标记使用原标签预览，另外两类隐藏预览。切换仅控制可见性，保留控件与草稿，保存发现跨分类错误时先切换分类再展开并聚焦输入。预览复用渲染和 CSS，但不创建真实入口 id、不绑定移动或打开面板行为。全局恢复默认与局部恢复外观均只改草稿；局部恢复不改显示范围或位置。保存成功后刷新当前真实入口外观，关闭放弃则不应用。

### 4. 共用位置与可清理的指针交互

沿用 `bvh_panel_position` 的 `{ left: 'Npx', top: 'Npx' }`，两个入口共用。有限 px 坐标允许读取后按边界限制，损坏或非 px 数据回默认左下角。默认锚点为 left/bottom 各 15px；拖拽后改为 left/top，并清除 bottom。设置页和菜单恢复位置调用同一方法，清除存储，立即恢复当前入口，隐藏状态下也能清除。

用 Pointer Events 与 pointer capture 统一鼠标和触摸，保留 5px 阈值。超过阈值视为拖拽，结束后抑制紧随的 click，只有正常结束才提交位置；取消时恢复拖拽前位置并清理状态。普通 click 与键盘 Enter／Space 只打开一次面板。入口移除时释放捕获和临时监听器；resize 监听全局只绑定一份或随实例明确释放。

按实际元素尺寸约束 left/top，常规边缘保留 8px，默认位置仍为 15px。首显、拖拽、resize、大小／模式变化和内容高度变化后执行边界检查；可用视口小于期望宽度时限制 max-width。被动视口校正不频繁写 GM，只有拖拽完成保存位置，避免缩小窗口覆盖用户的原布局意图。

### 5. 验证复用现有工具

复用 `tools/bilibili-history/harness.mjs` 的 GM stub 和脚本注入方式，扩展测试暴露仅限所需的外观辅助方法。新增聚焦的浮层行为测试，覆盖旧设置、无效值、草稿隔离、保存失败、四种 visibility、无记录视频回退、拖拽误点击及位置恢复。回归运行 `tag-style-test.mjs`、`startup-test.mjs` 和 `player-test.mjs`，确认设置布局调整、启动状态和进度刷新不受影响；不新增测试框架。

使用本地浏览器夹具检查 1280px 与 390px 视口、明暗主题、自定义大小、两种模式和 60／100 透明度的代表组合，检查焦点、长分 P 名称和缺失字段。实际站点验证与本地夹具结果分开记录；提案阶段不运行实现验收。

## Risks / Trade-offs

- [信息模式切换改变尺寸] → 更新布局后重算边界，保留坐标意图；明确移动位置与外观配置独立。
- [任意强调色及半透明背景降低辨识度] → 固定正文主题色、限制最低不透明度、保留文字状态，在复杂背景夹具中检查。
- [页面更新销毁正在拖拽的入口] → 常规进度更新复用节点，真正切页时取消指针会话并清理监听。
- [既有测试依赖设置分组数量或 p 元素] → 修改只反映用户行为的断言，保留原有功能校验，不以更新快照掩盖回归。
- [两种入口现在共用拖拽位置] → 这是明确新增的统一行为，已有视频位置直接沿用，恢复操作对两者一致。

## Migration Plan

实现时新增默认值和字段级归一化，无需批量迁移或改写历史记录。已有位置按原格式读取。回退旧脚本时旧代码忽略新增字段，仍能读取原位置和记录；不删除新字段以便重新升级。版本、README 与 CHANGELOG 等到用户明确要求收尾或提交时统一处理。

## 用户反馈调整（2026-09-25）

根据页面实测截图收紧布局：非视频页删除重复说明与固定卡片宽度；视频页三档宽度改为 160/168/184px、内边距改为 8/9/10px，缩小进度字号及区块间距，保留完整保存时间与观看信息。

后续反馈进一步替代上述固定尺寸：大小改为 80%–160% 的滑块与数字输入，默认 100%，旧 small/medium/large 映射为 92/100/108。视频入口按内容自适应宽度，观看时间为基础字号的 1.85 倍、状态为 0.85 倍、保存时间为 0.75 倍；百分比紧邻观看时间，保存时间去掉“保存于”前缀，垂直间距以 em 随比例缩放。保留视口宽度限制与位置校正，不使用 transform 缩放。
