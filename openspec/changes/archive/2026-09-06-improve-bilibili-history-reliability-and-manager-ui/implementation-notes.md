## 最新实现：无需打开管理面板的后台整理

普通页面完成局部初始化后自动延后两秒检查整理状态，独立存储实例在后台读取和整理，不升级前台局部视图、不占用前台保存队列，每次后台存储操作让出事件循环。页面关闭停止后续后台操作。完成时更新完整路由索引及 `bvh_grouping_complete_v1` 覆盖清单，并通知页面同步；后续访问仅检查清单和新增提交，已完成且无新增跨组事务时不读取历史数据块或重写检查点。新导入跨组事务也触发整理。

已提交且仍覆盖当前版本的分组检查点作为持久进度；中断后重新读取并校验，复用完整组，只补齐未完成或已变化的组。重启仍需要读取校验，不能宣称完全零重读。未提交的暂存块保留，沿用原有离线清理要求。替代副本物理时间取已读取提交的最大时间之后，避免同毫秒跨页写入阻止旧事务回收，业务版本不变。

更正下文历史说明：旧实现未完成整理前可能每次加载都慢，并非仅首次；本次已取消手动打开历史管理的前提。升级后首次完整旧事务校验仍可能耗时，后台完成前关闭页面会在下次继续，真实环境耗时仍待用户复测。
