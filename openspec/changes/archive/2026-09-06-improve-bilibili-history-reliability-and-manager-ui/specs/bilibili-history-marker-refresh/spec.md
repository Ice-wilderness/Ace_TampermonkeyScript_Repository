## Purpose

使页面上已有的观看标签和进度条能够正确反映配置、记录与分 P 详情的变化，同时将更新限制在实际受影响的内容，并保证关闭管理面板后不再保留无用订阅和渲染任务。

## ADDED Requirements

### Requirement: 已有标记响应显示设置
系统 MUST 在显示设置正式保存后刷新已有可见标记，包括恢复默认值后保存的情况，不得仅因视频 key 与标签文字未变化就跳过更新；尚未保存的草稿只影响预览区。

#### Scenario: 关闭已有卡片的进度条
- **WHEN** 一张卡片已显示观看进度条，用户关闭进度条并保存
- **THEN** 该卡片的进度条 MUST 消失，无需刷新页面或更换视频

#### Scenario: 更改标签位置透明度或阈值
- **WHEN** 用户修改标签位置、透明度或进度阈值并保存
- **THEN** 已有可见标签 MUST 使用新的位置、透明度与状态颜色
- **AND** 其视频归属和记录内容 MUST 保持正确

### Requirement: 标记详情随记录更新
系统 MUST 在进度、保存时间或关联分 P 发生变化时更新标签提示与进度条，即使主标签文字没有变化。

#### Scenario: 多 P 主标签不变但详情变化
- **WHEN** 主标签仍显示“已记录 多P”，其中一个分 P 的进度或时间发生变化
- **THEN** 提示内容 MUST 展示新的分 P 详情

### Requirement: 数据变更只更新受影响内容
系统 SHALL 让普通记录变更仅更新相关视频及其基础视频聚合标记；仅全局显示设置变化或整体数据失效时进行广泛刷新。

#### Scenario: 保存单个视频进度
- **WHEN** 只有一个视频的进度发生变化
- **THEN** 其他无关视频的既有标签 MUST 不被移除重建
- **AND** 受影响内容进入可见区域时 MUST 展示最新状态

### Requirement: 面板关闭释放更新订阅
系统 MUST 在管理面板关闭或被替换后释放该面板的订阅与待执行任务，重新打开时只保留当前实例所需的订阅。

#### Scenario: 反复打开关闭管理面板
- **WHEN** 用户连续打开关闭管理面板 20 次，再修改一条历史记录
- **THEN** 已关闭面板 MUST 不执行数据渲染，活动订阅数量 MUST 不随历史打开次数增加
