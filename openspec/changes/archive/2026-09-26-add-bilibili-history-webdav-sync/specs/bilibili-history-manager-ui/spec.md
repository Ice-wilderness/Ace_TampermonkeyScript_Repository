# Spec Delta

## MODIFIED Requirements

### Requirement: 管理面板采用完整统一的视觉体系
管理面板 MUST 统一布局、导航、排版、间距、表单、按钮和状态反馈，使用深石墨导航、暖白内容背景与蓝色主操作；偏好设置、历史管理、数据统计及新增云同步四个并列模块与公共弹窗 MUST 使用一致的视觉规则。

#### Scenario: 桌面打开管理面板
- **WHEN** 用户在桌面视口通过现有入口打开管理面板
- **THEN** 系统 MUST 默认显示设置页，提供清晰的侧栏导航、页标题、内容区和关闭入口
- **AND** 四个模块 MUST 具有可识别的当前选中状态和一致的控件样式，云同步 MUST 有独立导航入口，不藏在维护分类

#### Scenario: 空数据与有数据均可展示
- **WHEN** 用户分别查看空历史、少量记录和大量记录
- **THEN** 各模块 MUST 提供适合当前状态的布局，不得依赖虚构统计数字或真实视频封面才能成立
- **AND** 云同步未配置、同步中、无备份、失败及待选择状态 MUST 均有完整布局和明确操作，不能只显示一排无说明按钮

### Requirement: 页面隔离与现有入口兼容
新界面 MUST 仅作用于脚本自己的界面区域，保留现有入口与悬浮按钮隐藏规则，不依赖外部视觉资源；除用户配置后主动执行或启用定时任务所需的 WebDAV 请求外，面板 MUST 不增加页面请求。

#### Scenario: 管理面板与 Bilibili 原页面共存
- **WHEN** 用户在现有匹配页面打开、操作并关闭管理面板
- **THEN** 原页面导航、播放器、按钮和布局 MUST 不被脚本的面板样式污染
- **AND** 关闭后原页面滚动状态 MUST 恢复，观看记录功能 MUST 继续运行

#### Scenario: 云同步入口按需联网
- **WHEN** 用户仅打开面板但未请求 WebDAV 操作，且自动同步未启用
- **THEN** 面板 MUST 不因渲染其他模块而发起 WebDAV 请求；备份列表 MUST 在用户打开云同步模块或刷新时按需加载

## ADDED Requirements

### Requirement: 云同步工作台具有清晰信息层级
云同步模块 SHALL 分别呈现同步状态与主操作、连接配置、同步与保留策略、备份列表及恢复入口；控件、标题、间距、边框、图标和状态色 MUST 与既有管理面板一致，错误与危险操作不得只靠颜色区分。

#### Scenario: 查看与配置云同步
- **WHEN** 用户打开云同步模块
- **THEN** 顶部 MUST 能直接查看当前状态、最近成功同步时间及立即同步入口，连接配置、策略和备份区 MUST 有明确分组与主次操作
- **AND** 配置未保存时 MUST 显示草稿状态，切换到其他模块再返回不丢草稿；关闭管理面板沿用保存、放弃、继续编辑流程

#### Scenario: 窄屏浏览独立模块
- **WHEN** 用户在 390 像素宽视口打开云同步模块并切换四个导航入口
- **THEN** 导航、连接表单、备份列表与操作区 MUST 可读可用且无整体横向溢出，必要内容可以纵向滚动
- **AND** 操作状态刷新 MUST 不重置输入、焦点或滚动位置

### Requirement: 云同步控件使用一致的定制外观
系统 SHALL 为云同步的输入、按钮、同步频率选项、保留天数、备份选择及恢复确认提供统一设计的外观和 hover、focus、selected、disabled、loading、error 状态；MUST 不使用浏览器默认 alert／confirm／prompt 完成用户流程，也不得依赖未定制原生 select、数字微调器或日期选择器呈现主要交互。

#### Scenario: 修改同步频率和备份设置
- **WHEN** 用户操作关闭／每小时／每天选项、保留天数或备份列表
- **THEN** 频率 MUST 使用同风格分段选项，保留天数 MUST 使用带单位及字段错误的定制输入，已有备份 MUST 通过设计过的列表选择而非原生日期弹框
- **AND** 文本与密码输入 MUST 支持正常输入、复制粘贴、密码管理器及标签关联，不为外观丢弃基础语义

#### Scenario: 键盘操作与恢复确认
- **WHEN** 用户使用 Tab、方向键、Enter、Space 或 Escape 操作相应控件与恢复弹窗
- **THEN** 控件 MUST 按其语义响应，具有可见焦点及可访问名称；恢复和本地／云端选择 MUST 使用脚本自有统一弹窗，保留焦点管理与取消路径
- **AND** 自定义外观 MUST 不引入外部组件库、远程字体或持续装饰动画，自动同步仍遵循静默规则
