# Spec Delta

## Purpose

规范 Bilibili 视频页及播放列表场景中各类列表观看标签（纯分 P 列表、合集单 P、合集嵌套分 P、通用列表变体、网格分 P 与播放器选集菜单）的放置位置、与时长列的纵向对齐、长标题截断保护、双外观兼容及无时长降级行为，同时保持设置预览与真实页面布局一致。

## ADDED Requirements

### Requirement: 带时长的文字播放列表将观看标签置于时长左侧
系统 MUST 将带有时长列的文字播放列表条目中的观看标签渲染在行内时长区域的紧邻左侧，使同一列表内各行的标签与时长之间保持一致的间距并沿时长列左侧纵向对齐，而不是紧跟在长短不一的标题文字末尾。

#### Scenario: 合集嵌套分 P 子条目对齐到时长左侧
- **WHEN** 用户查看合集中展开的多 P 子列表，各分 P 标题长度不同且存在已观看或已访问记录
- **THEN** 每行的观看标签 MUST 位于该行时长区域的紧邻左侧，形成沿时长列左边缘对齐的一列
- **AND** 标签与标题文字之间 MUST 保留适当视觉间隔，不得随标题长短左右参差错位

#### Scenario: 合集单 P 条目对齐到时长左侧
- **WHEN** 用户查看合集中的单 P 视频条目，且该条目存在应显示的观看记录
- **THEN** 观看标签 MUST 位于该行时长区域的紧邻左侧，与同合集内的嵌套分 P 子条目保持一致的对齐方式

#### Scenario: 纯分 P 列表视图对齐到时长左侧
- **WHEN** 用户查看普通多 P 视频的列表视图，且分 P 存在应显示的观看记录
- **THEN** 观看标签 MUST 位于该行时长区域的紧邻左侧，而不是嵌入在标题文本容器内部

#### Scenario: 通用带时长列表变体对齐到时长左侧
- **WHEN** 页面上出现其他带时长节点的视频列表条目，且该条目存在应显示的观看记录
- **THEN** 系统 MUST 将观看标签放置在对应时长节点之前，而非标题文字内部

### Requirement: 长标题与双标签样式下不挤压或裁切标签与时长
系统 MUST 确保列表条目在超长标题、经典标签（完整或精简文字、自定义字号与左右留白）以及 SVG 圆环样式下，标签与时长列均完整可见且不被压缩，标题在左侧独立截断。

#### Scenario: 超长无空格标题与经典标签共存
- **WHEN** 列表条目的标题超出可用宽度，且配置为完整文字或较大字号的经典标签
- **THEN** 标题文本 MUST 在左侧区域独立截断，观看标签与右侧时长 MUST 保持完整宽度与可读性且不溢出列表行

#### Scenario: 列表条目使用 SVG 圆环进度样式
- **WHEN** 用户将列表标签样式设为 SVG 圆环并设置有效直径，且记录包含观看百分比
- **THEN** 圆环 MUST 显示在时长区域左侧、保持正圆不压扁且文字完整居中
- **AND** 圆环 MUST 不被标题区域的溢出裁切规则截断

### Requirement: 列表标签刷新保持幂等并在结构变化时自愈
系统 SHALL 在记录与样式均未变化且标签已处于预期位置时避免重复改写 DOM；当页面框架动态移除标签或延迟补全时长节点时，刷新 MUST 将标签恢复或校正到时长左侧。

#### Scenario: 重复刷新已正确定位的列表条目
- **WHEN** 同一列表条目的记录、配置与 DOM 结构未发生变化，系统再次执行该条目的标记处理
- **THEN** 系统 MUST 复用既有标签节点且不产生多余的 DOM 节点增删或移动

#### Scenario: 时长节点延后出现或标签被框架移除
- **WHEN** 页面框架在首次标记后补充时长节点、重排子节点或移除了脚本插入的标签，随后触发刷新
- **THEN** 系统 MUST 重新将标签放置到时长节点的紧邻左侧，并保证同一条目内仅存在一个观看标签

### Requirement: 无时长条目与非文字列表保持兼容边界
系统 MUST 对缺失时长节点的文字列表条目提供安全降级，并保持网格分 P、播放器内选集菜单、播单封面列表及合集折叠头的既有标记方式不变。

#### Scenario: 文字列表条目缺少时长节点
- **WHEN** 一个非网格、非播单封面的列表条目中不包含时长区域或时长节点
- **THEN** 系统 MUST 降级将标签挂载到该条目内可用的标题外侧或行容器末尾，不抛出异常且不丢失观看标记

#### Scenario: 网格分 P 视图保持角标定位
- **WHEN** 用户将纯分 P 列表切换为网格编号视图
- **THEN** 观看标签 MUST 继续以紧凑角标形式显示在方格右上角

#### Scenario: 播放器内选集菜单与播单封面列表保持不变
- **WHEN** 用户打开播放器内选集菜单或浏览带封面的播单列表
- **THEN** 播放器选集菜单 MUST 保持既有右侧纵向对齐与标题右侧留白
- **AND** 播单图文列表 MUST 继续在封面图角落显示封面标签，合集多 P 折叠头 MUST 保持不直接打标

### Requirement: 设置页列表预览反映时长左侧布局
系统 SHALL 在设置页的观看标记预览区中展示包含标题、观看标签与示意时长的合集列表预览行，使标签位于示意时长左侧，与真实页面的列表布局保持一致。

#### Scenario: 在设置页预览经典标签与圆环样式
- **WHEN** 用户在设置页切换经典标签、精简文字或 SVG 圆环并调整尺寸参数
- **THEN** 列表预览行 MUST 即时展示位于示意时长左侧的标签效果，在桌面与 390 像素窄视口下均不发生横向溢出
