# 油猴脚本合集

这里整理了多个自用油猴脚本。脚本文件统一放在 `scripts/` 目录；每个脚本独立维护，后续新增脚本时也会在本文档中加入对应分区。

## 脚本列表

- [ChatGPT 图片批量下载器](#chatgpt-图片批量下载器)

- [bilibili 查看关注时间](#bilibili-查看关注时间)

- [自用论坛辅助签到](#自用论坛辅助签到)

## 通用安装方式

1. 安装 Tampermonkey、Violentmonkey 或其他兼容的用户脚本管理器。
2. 在脚本管理器中新建脚本。
3. 将对应 `.js` 文件内容粘贴进去并保存。
4. 打开匹配网站后脚本会自动运行。

## ChatGPT 图片批量下载器

文件：[ChatGPT 图片批量下载器.js](./scripts/ChatGPT%20图片批量下载器.js)

用于在 ChatGPT 图片页面批量选择并下载图片。脚本会为图片卡片添加复选框，并通过 ChatGPT 页面原生保存/下载按钮依次触发下载。

### 主要功能

- 在 ChatGPT 图片页面为候选图片添加复选框。
- 右下角显示批量下载面板，支持全选、取消全选和查看已选数量。
- 批量下载时逐张打开目标图片，并优先使用页面原生保存/下载按钮。
- 在图片查看器已打开时，可通过缩略图切换到目标图片，降低重复下载当前图片的风险。
- 部分图片下载失败时，会自动取消成功图片勾选，仅保留失败图片，便于直接重试。
- 支持 ChatGPT SPA 页面切换、懒加载图片和明暗色模式。

### 兼容页面

- `https://chatgpt.com/images*`
- `https://chat.openai.com/images*`

### 权限说明

- `GM_addStyle`：注入复选框和批量下载面板样式。

## Bilibili 视频观看历史记录

文件：[Bilibili视频观看历史记录.js](./scripts/Bilibili视频观看历史记录.js)

用于记录 Bilibili 视频访问和观看进度，并在首页、搜索页、历史页、稍后再看、视频推荐、合集/分 P 列表等位置标记已观看内容。

### 主要功能

- 自动记录视频访问状态和观看进度。
- 在视频封面上显示已访问、已观看、观看百分比或多 P 记录提示。
- 支持普通分 P 视频、合集视频、合集变种页面、UP 主投稿播放列表和播放器选集列表。
- 支持进度条显示、标签位置、标签透明度、低/高进度阈值配置。
- 支持续播提示，可跳转到上次观看进度。
- 支持在 Bilibili 历史页通过悬浮按钮同步当前已加载的官方观看历史，继续同步时会滚动加载更多记录；多 P 视频会按链接中的分 P 精确保存。
- 内置设置面板、历史管理与统计面板，支持可视化统计图表（完成度环形图、状态/进度分布图、近期趋势柱状图）和按保留周期清理久远历史。
- 采用分片存储，减少大量历史记录时的读写压力。
- 提供 localStorage 临时备份恢复，降低异常退出时丢失进度的概率。
- 支持在设置页下载脚本调试日志：当前页面导出完整日志，历史页面仅保留 warning/error、页面异常和控制台 warn/error，便于排查卡死、自动跳转或脚本冲突问题。

### 设置、历史与统计

- 脚本设置页：配置进度条、悬浮按钮隐藏规则、标签样式、进度阈值、调试日志等。
- 历史管理：按标题/BV/av 搜索（带清空按钮）、按状态筛选、按多种方式排序、分页浏览、单条/批量删除并支持撤销、导入导出 JSON，可按保留 N 天/月/年清理久远记录并显示删除进度。
- 历史页同步：在 Bilibili 历史记录页点击悬浮按钮同步当前已加载卡片；再次点击会滚动到底部、等待更多卡片加载后继续同步。脚本保留更长观看进度，进度差距在 5 个百分点以内时跳过同步。
- 统计面板：总记录/已观看/已访问/进度分布等数字卡片，以及完成度环形图、状态进度条形图、近期趋势柱状图。

### 数据说明

脚本使用 `GM_setValue` / `GM_getValue` 保存数据，并将记录拆分到多个分片键中。历史记录 key 通常为：

- `BVxxxxxxxxxx`
- `BVxxxxxxxxxx?p=2`
- `av123456`

普通单 P 视频记录为基础 key，多 P 视频会按分 P 保存为 `?p=` key。

### 配置项

- 是否显示进度条。
- 是否显示已访问标记。
- 是否显示自动续播提示。
- 悬浮按钮隐藏规则：不隐藏、隐藏视频页悬浮按钮、隐藏非视频页悬浮按钮或全部隐藏。
- 是否开启调试日志，并可下载或清空脚本调试日志。
- 标签透明度。
- 标签位置。
- 低进度和高进度阈值。

### 兼容页面

- 视频页。
- 首页和带查询参数的首页。
- 动态页。
- 空间页。
- 历史页。
- 稍后再看。
- 搜索页。
- 合集、播放列表相关页面，包括 `/medialist/play/` 和 `/list/` 投稿播放列表。

## bilibili 查看关注时间

文件：[bilibili查看关注时间.js](./scripts/bilibili查看关注时间.js)

用于在 Bilibili 页面显示当前登录账号关注某个用户的时间。脚本会同步并缓存关注列表数据，在关注/粉丝列表、用户主页和全站用户悬浮名片中注入“关注于”时间标签。

### 主要功能

- 在关注列表和粉丝列表中显示对应用户的关注时间。
- 在已关注用户的个人主页昵称区域显示关注时间。
- 在视频页、动态页等页面的用户悬浮名片中显示关注时间。
- 自动同步当前登录账号的关注列表，并将关注时间缓存到本地。
- 视频播放相关页面仅显示已有缓存或接口可查询的悬浮名片标签，不触发关注列表全量同步。
- 当页面中出现本地库缺失的用户，或缓存超过一定时间后，会自动触发全量同步。
- 支持 Bilibili SPA 页面切换和 DOM 重绘后的自动补标，减少标签错位或漏标。

### 数据说明

脚本使用 `GM_setValue` / `GM_getValue` 保存数据，并按登录账号 UID 和列表类型隔离缓存。常见存储键格式为：

- `BiliFollowDB_followings_登录账号UID`
- `BiliFollowDB_followers_目标账号UID`

缓存内容包含最后同步时间、列表总数和用户 UID 到关注时间戳的映射。全量同步时会用最新列表覆盖旧数据，可自动移除已取关用户的旧记录。

### 使用说明

- 需要先登录 Bilibili，脚本通过登录 Cookie 中的 `DedeUserID` 区分本地缓存。
- 首次使用或缓存过期时会进行后台同步，同步期间右下角会显示进度提示。
- 为降低接口风控风险，同步关注列表时每页会间隔约 1.5 秒。
- 若关注列表很大，首次同步可能需要等待一段时间；同步完成后后续页面显示会更快。

### 兼容页面

- `https://space.bilibili.com/*`
- `https://m.bilibili.com/*`
- `https://www.bilibili.com/*`
- `https://t.bilibili.com/*`

### 权限说明

- `GM_xmlhttpRequest`：请求 Bilibili 关系接口获取关注时间。
- `GM_setValue` / `GM_getValue`：保存和读取本地关注时间缓存。
- `@connect api.bilibili.com`：允许访问 Bilibili API。

## Discuz 论坛帖子已读标记与图片预览

文件：[Discuz 论坛帖子已读标记与图片预览.js](./scripts/Discuz%20论坛帖子已读标记与图片预览.js)

用于 Discuz! 论坛浏览辅助。脚本会记录已访问帖子，在论坛列表中标记已读状态，并可在列表页静默自动预览帖子首屏图片；开启后续分页选项后，也可手动继续加载更多图片。

### 主要功能

- 自动记录访问过的帖子，并在论坛列表中以“[已访问]”标记显示。
- 在帖子列表中静默自动预览帖子第 1 页图片，默认最多展示 5 张。
- 自动预览不足 5 张时不会继续抓取后续页，降低列表滚动时的请求量。
- 自动预览不会写入“已看图”标记；若第 1 页无图，会隐藏预览区域并将按钮显示为“无图片”。
- 默认只抓取帖子第 1 页图片；若第 1 页图片超过自动预览数量，预览网格末尾会显示“加载更多图片”卡片用于补完本页剩余图片。
- “加载更多图片”卡片会自动对齐当前最后一张图片的高度；开启“允许手动抓取后续分页”后，还可继续抓取后续 3 页图片，并记录看图状态。
- 支持常见动态 URL 和伪静态 URL 的分页预览。
- 图片预览使用瀑布流网格展示，并过滤过小图片。
- 折叠预览后会在按钮上保留已加载图片数量。
- 支持图片灯箱查看，可用左右按钮、图片左右区域点击和键盘方向键翻页，按 `Esc` 关闭。
- 手动预览过图片但未正式打开的帖子会以“[已看图]”标记区分。
- 已访问帖子支持多种显示样式：灰底标签、半透明、删除线、半透明加删除线、仅改变标题颜色或隐藏已读帖子。
- 自动限制历史记录数量，避免长期使用后存储数据持续膨胀。
- 支持同论坛名、不同域名的存储隔离，并包含旧存储键自动迁移逻辑。

### 设置与数据管理

脚本在用户脚本管理器菜单和页面右下角可拖动悬浮按钮中提供“Discuz 辅助设置”入口，面板分为图片预览、已读样式和数据管理：

- “图片预览”：开启或关闭图片预览、自动预览、后续分页抓取，设置自动预览数量、自动预览并发数和最小图片边长。
- “已读样式”：选择已访问帖子的显示模式。隐藏已读帖子只隐藏真实访问过的帖子，不隐藏仅看图帖子。
- “数据管理”：查看当前论坛域的足迹数量、已访问数量、仅看图数量、最近记录时间和存储 key，并支持导出、导入、清理 30 天前足迹或清空全部足迹。

导出数据为 JSON 文件，文件名包含论坛名和域名标识。导入时会合并本地数据，并优先保留时间戳较新的记录。

### 数据说明

脚本使用 `GM_setValue` / `GM_getValue` 保存每个论坛域的记录。当前存储键格式为：

- `discuz_visited_threads_论坛名_域名`

单条记录会保存帖子访问状态、图片预览状态和更新时间戳。记录数量超过阈值时会自动保留较新的记录。

图片预览结果会按论坛域、帖子 ID 和分页结果缓存在当前浏览器会话中，缓存带有时间戳，过期后会重新抓取。默认只使用帖子第 1 页缓存；开启后续分页抓取并手动加载更多图片时，才会继续写入后续分页缓存。

### 兼容页面

- `*://*/*forum.php?mod=forumdisplay*`
- `*://*/*forum.php?mod=viewthread*`
- `*://*/*forum-*-*.html`
- `*://*/*thread-*-*.html`

### 权限说明

- `GM_setValue` / `GM_getValue` / `GM_deleteValue`：保存、读取和删除已读与看图记录。
- `GM_registerMenuCommand`：注册 Discuz 辅助设置菜单；页面内还会注入可拖动悬浮设置按钮。
- `GM_addStyle`：注入已读标记、预览网格、设置面板和灯箱样式。

## 自用论坛辅助签到

文件：[自用论坛辅助签到自写.js](./scripts/自用论坛辅助签到自写.js)

用于个人论坛签到和论坛页面辅助。脚本会在各支持站点继续执行自动签到逻辑，并在 `limestart.cn` 提供每日签到控制台。

### 主要功能

- 在 `limestart.cn` / `www.limestart.cn` 显示每日签到控制台入口。
- 支持按启用清单一键处理未完成站点：可并发对已适配站点直接从控制台发送签到请求，其余站点按后台、前台或手动方式打开。
- 控制台直签失败后会等待 3 秒自动重试，最多尝试 3 次后才保留最后一次失败结果。
- 一键处理或一键直签后会短时自动刷新控制台状态，减少手动点击刷新状态的次数。
- 展示每日状态、更新时间、失败/需登录/需前台处理等提示，并支持手动标记成功、失败或跳过。
- 支持在实际签到页面顶部显示持续状态提示，展示签到中、成功或失败原因；成功提示可当天不再提示，已完成提示会自动关闭并限制当天显示次数。
- 支持添加、编辑、启用/禁用自定义签到目标。
- 支持对需要人工验证的站点打开前台页面，验证完成后再由页面脚本确认签到状态。
- 支持登录访问即自动发放奖励的站点，确认登录态后记录当日完成。
- 支持失败请求调试日志导出，保留最近 3 天失败记录，便于排查站点登录态、接口响应和验证页问题。
- 可选启用提醒状态下 3 秒后自动展开控制台，悬浮按钮会显示倒计时并可取消本次自动展开。
- 可选启用签到动作完成后自动关闭站点页面；脚本本次完成点击、提交、接口签到或特定站点从控制台打开后确认成功时会尝试关闭，普通打开页面时已签到不会关闭。

### 兼容页面

- 控制台入口：`https://limestart.cn/*`、`https://www.limestart.cn/*`。
- 自动签到站点：脚本头部 `@match` 中列出的论坛与资源站页面。
- 老王论坛 `https://laowang.vip/*` 采用前台签到流程，遇到站点点击验证时需在前台完成后再确认状态。
- 有叽叽论坛 `https://www.uu-gg.one/*` 因 Cloudflare 验证限制，采用后台打开签到页后由页面内 API 提交并检测完成状态。

### 维护说明

- 本脚本独立维护。
- 控制台配置和每日状态使用脚本本地 GM 存储保存，既有签到成功日期记录会继续兼容。
- 后续变更会在 [CHANGELOG.md](./CHANGELOG.md) 中按脚本分区记录。

## 通用请求抓包记录器

文件：[通用请求抓包记录器.js](./scripts/通用请求抓包记录器.js)

用于临时记录网页中的常见请求，辅助分析论坛签到等接口。脚本默认不会抓取所有站点，需要在脚本管理器菜单中按当前站点启用，刷新后生效。

### 主要功能

- 按站点启用或暂停抓包，避免长期记录无关页面请求。
- 记录 `fetch`、`XMLHttpRequest`、`sendBeacon`、普通表单提交和链接点击。
- 表单记录支持 `formaction`、`formmethod`、`formenctype`、`formtarget` 等提交按钮覆盖属性。
- 导出当前站点日志为 JSON 文件，便于后续分析接口地址、请求参数和响应文本。
- 对 token、密码、Cookie、session 等敏感字段做基础脱敏，并限制请求体和响应体记录长度。

### 使用说明

1. 在目标站点打开脚本管理器菜单，点击“抓包：启用当前站点并刷新”。
2. 执行需要分析的网页操作，例如点击签到按钮。
3. 再次打开脚本管理器菜单，点击“抓包：下载当前站点日志文件”。
4. 使用完后可点击“抓包：暂停当前站点（刷新生效）”，并按需清空当前站点日志。

### 兼容页面

- `*://*/*`

### 权限说明

- `GM_setValue` / `GM_getValue` / `GM_deleteValue`：保存启用站点配置和当前站点日志。
- `GM_registerMenuCommand`：注册启用、暂停、下载和清空日志菜单。
- `unsafeWindow`：尽早挂载页面侧请求 hook。
